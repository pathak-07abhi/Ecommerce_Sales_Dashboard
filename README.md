## 🚀 About

This project focuses on building a **clean, interactive, and insight-driven E-commerce Sales Dashboard** using Power BI. The goal was simple: help decision-makers quickly understand business performance without digging into raw data.

The dashboard provides a **Year-to-Date (YTD)** view of sales, profit, margins, and quantity sold, enabling users to track trends, compare regions, and identify growth opportunities at a glance.

---
## 🎯 Objectives

- 📌 Monitor overall business performance using key KPIs
- 📌 Analyze sales and profit trends over time
- 📌 Compare performance across regions, states, and product categories
- 📌 Enable dynamic filtering for quick exploration
- 📌 Support data-driven decision making

---

## 🧰 Tools & Technologies

- **Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning, transformation, and ETL
- **DAX (Data Analysis Expressions)** – Measures and time intelligence calculations
- **Data Modeling** – Building relationships for accurate analysis

---

## 🔄 Project Workflow

### 1️⃣ Data Import & Preparation

- Imported raw sales data from Excel files
- Cleaned and transformed data using Power Query:
  - Removed duplicates
  - Standardized column names
  - Fixed data types
  - Handled missing values

### 2️⃣ Data Modeling

- Created a **Calendar Table** using DAX for time-based analysis
- Built relationships between fact and dimension tables
- Optimized the data model for performance and accuracy

### 3️⃣ Dashboard Design & Development

- Designed a user-friendly and visually balanced layout
- Created custom **DAX measures** for KPIs
- Added interactive elements such as slicers and filters
- Used a consistent color theme for clarity and readability

---

## 📊 Key KPIs Tracked

- 💰 **YTD Sales** – Total revenue generated year to date
- 📈 **YTD Profit** – Overall profitability
- 📊 **YTD Profit Margin** – Profit efficiency
- 📦 **Quantity Sold** – Total units sold

---

## 📈 Visualizations Used

- 📌 KPI Cards for high-level metrics
- 📊 Bar & Column Charts for category comparison
- 🟠 Donut Charts for contribution analysis
- 📉 Area Charts for trend analysis
- 🗺️ Maps for regional and state-wise insights
- 🎚️ Slicers for dynamic filtering

## 🔍 Insights & Observations

- Certain regions consistently outperform others in terms of sales and profit
- A small number of product categories contribute a large share of revenue
- Profit margins vary significantly across states and regions
- Seasonal trends are clearly visible through YTD analysis

These insights can help businesses refine pricing strategies, optimize inventory, and focus marketing efforts more effectively.

## 📌 Key Takeaways

- DAX plays a major role in unlocking advanced analytics
- Visualization design matters as much as the data itself
